# MeshHome brand assets

| File | Use |
| --- | --- |
| `meshhome-icon-1024.png` | The app icon: roof and signal mark over the two-tone name (App Store, README, large sizes) |
| `meshhome-mark.svg` | The mark alone, transparent background (headers, next to the name) |
| `meshhome-favicon.svg` | The mark on a white rounded square (browser tabs and other small sizes) |

Colours: ink `#0f172a` (the roof and "Mesh"), teal `#0d9488` (the signal and "Home"). The name is
set in Poppins Bold. In dark mode, draw the roof and "Mesh" in the text colour instead of ink.

MeshHome works with MeshCore radios but is not affiliated with the MeshCore project; don't combine
these assets with MeshCore's logo.
